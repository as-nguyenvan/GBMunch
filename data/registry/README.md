# Registry artifacts

- `organizations.jsonl` / `organizations.csv` — canonical UF orgs from GatorConnect (emails redacted).
- `event_sources.jsonl` / `event_sources.csv` — public event-source seed list.

Instagram `HIGH` = explicit GatorConnect link. `MEDIUM` = single homepage link candidate; treat as unverified until reviewed.

Raw GatorConnect dumps are intentionally excluded from this repository.
